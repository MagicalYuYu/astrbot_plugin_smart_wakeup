PHILOSOPHY

会主动 · 知进退 · 可调校

大多数群机器人只有两种状态：被 @ 才应，不 @ 装死。灵犀把真人的"社交节律"做成了引擎

🗣️

会主动

Proactive

不只是被动应答——AIF 三要素主动发言引擎定时感知群内氛围，该开口时才开口

  • AIF 主动发言引擎（旁观监测 ⇄ 主动主导）
  • 9 类话题 + 自定义话题 + 按群加权
  • Fetcher 资讯注入：RSS 15 源 4 类 + 新闻 API
  • 6 种开头模式池，主动发言不复读自己
🧭

知进退

Tactful

被无视时知趣收声，被嫌弃时主动潜水——像真人一样懂得什么时候该闭嘴

  • 五路退却信号，任一触发即收声
  • 递进退让 2h / 6h / 24h，不死缠烂打
  • [SKIP] 沉默权 + 小模型合规判别
  • 多段跨天静默时段，有作息表
🎛️

可调校

Tunable

143 项参数 × 专属可视化面板——同一只 Bot，在每个群都可以有不同的性格

  • 专属 Web 配置面板，非 schema 冗长表单
  • 21 项参数按群覆盖 + 用户概率乘数
  • Token 四维统计 + σ 异常告警
  • 预设一键切换整体性格

TUNING

调出一只合群的 Bot

专属可视化配置面板 + 精细到单群单人的调校体系

🖥️

专属 Web 配置面板

不是 schema 自动生成的冗长表单：分组标签、实时状态 5 秒轮询、预设一键切换、测试发言、日志控制台、未保存提醒

🔧

143 项可调参数

14 个配置分组，从精力恢复速率到话题权重全部可调，均有合理默认值开箱即用

🎚️

单群单人精调

21 项参数按群覆盖（group_overrides）+ 用户级回复概率乘数（user_prob_overrides，0 = 永不回复某人）

💰

Token 精算师

小模型上下文压缩 + 增量注入 + 四维度统计（模型/群组/小时/唤醒类型）+ σ 异常告警（σ=2.0）

🧠

分层对话记忆

近期原文（10 轮）+ 远期摘要（30 轮）+ 发送者归属 + 在场用户标注，主动被动共享，不张冠李戴

🖼️

图片双通道理解

框架图片描述直取为主（零成本）+ 自定义多模态模型降级识别兜底（image_context_custom_model）

面板入口：AstrBot WebUI → 插件管理 → 灵犀 → 配置面板；所有参数也可在插件配置中直接修改

INSTALL

几分钟装好即用

仅 2 个轻量 pip 依赖（feedparser + aiohttp），143 项参数均有合理默认值

推荐 · 上架审核中

插件市场安装

在 AstrBot 插件市场搜索「灵犀」或 astrbot_plugin_smart_wakeup，点击安装，依赖自动处理

AstrBot WebUI → 插件市场 → 搜索「灵犀」→ 安装

手动安装

1
克隆到插件目录
cd data/plugins git clone https://github.com/MagicalYuYu/astrbot_plugin_smart_wakeup.git
2
安装依赖（仅 2 个）
pip install -r astrbot_plugin_smart_wakeup/requirements.txt # feedparser>=6.0.0 · aiohttp>=3.8.0
3
重启并配置

重启 AstrBot 或在 WebUI 启用插件，然后在配置面板按需开启功能
