COMPARISON

没有灵犀 vs 有了灵犀

同样是群聊场景，灵犀让 Bot 的存在感从"工具"变成"伙伴"

😐

没有灵犀

用户 A · 14:02
今天天气真好啊

用户 B · 14:05
有人吗？聊聊天

（依然沉默 · 等待指令）
✨

有了灵犀

用户 A · 14:02
今天天气真好啊

是呀，这种天气特别适合出去走走～

有人吗？聊聊天
灵犀 · 14:05
在呢在呢，刚才还在想这天气适合干嘛呢
灵犀 · 14:06
你们有什么计划吗？

CAPABILITIES

六大核心能力体系

从感知到表达，灵犀构建了一套完整的"社交呼吸"系统

🎯

智能唤醒

多维度唤醒判定，让 Bot 在合适的时机自然介入对话

  • 名称提及即时唤醒
  • 精力值兴趣度评估
  • 冷场检测主动救场
  • 对话节奏智能识别
🌊

节律系统

精力与心流状态机协同，赋予 Bot 自然的呼吸节律

  • 精力值动态消耗与恢复
  • 五态心流状态机切换
  • 疲劳度自然累积
  • 昼夜节律适配
🧠

上下文记忆

多层级记忆系统，让 Bot 真正"记得"聊过什么

  • 短期对话窗口记忆
  • 长期用户画像积累
  • 群组氛围感知
  • 话题延续与切换
👁️

对话理解

多模态消息理解，不只是文字，图片也能看懂

  • 图片内容识别理解
  • 低信息量消息过滤
  • 复读行为识别
  • 情感倾向分析
✍️

输出处理

像真人一样说话，分段发送、情感润色、节奏自然

  • 长消息自动分段发送
  • 消息防抖避免刷屏
  • 情感语气润色
  • 响应延迟模拟真人
🛡️

安全控制

多重防护机制，确保 Bot 行为可控、成本可控

  • 群组白名单/黑名单
  • API 调用成本控制
  • 敏感内容过滤
  • 频率限制与冷却
INSTALL

三步快速安装

零文件依赖，装好即用，几分钟让 Bot 拥有社交呼吸

1

克隆仓库

将插件克隆到 AstrBot 的 plugins 目录下

cd plugins
git clone https://github.com/MagicalYuYu/astrbot_plugin_smart_wakeup.git
2

重启 AstrBot

重启 AstrBot 服务，插件将自动加载并初始化

# 重启你的 AstrBot 服务
# 插件会自动注册并加载
3

配置启用

在 AstrBot 管理面板中配置灵犀参数，按需开启功能

# 访问 AstrBot 管理面板
# → 插件管理 → 灵犀 → 配置
