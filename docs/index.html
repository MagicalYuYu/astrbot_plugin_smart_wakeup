⚙️ 原理

消息处理流程

每条群聊消息经过层层筛选和判断，最终决定 Bot 是否回复、如何回复——

1
📨 消息到达
群聊消息进入插件，记录到消息缓冲区
2
🚫 群组过滤
黑名单/白名单外的群直接跳过，指令前缀跳过
快速过滤
3
🔇 低信息量屏蔽
纯图片/贴纸/表情包等无效消息自动过滤
省 Token
4
🧠 心流状态更新
旁观 → 关注 → 心流 → 疲劳，四状态动态调整
状态机
5
🔍 唤醒判定
名称唤醒(确定性) / 关键词唤醒(概率) / 概率唤醒(动态) / 冷场救场(超时)
核心逻辑
6
🤚 消息防抖
等待用户停止发言，聚合多条消息后统一回复
不打断
7
🧩 上下文构建
分层记忆 + 增量注入 + 摘要压缩 + 图片识别
智能压缩
8
📤 输出处理
思考标签过滤 → 去重 → 智能分段发送 → 记录历史
像真人

🚀 安装

三步上手灵犀

安装简单，配置灵活——

Step 1
安装插件
在 AstrBot 插件市场搜索「灵犀」点击安装，或手动放入 data/plugins/ 目录。
Step 2
配置 Bot 名称
在 AstrBot WebUI → 插件管理 → 灵犀 → 配置中，设置 bot_name（必填）。
Step 3
开始使用
在群聊中 @Bot 或直接叫名字即可触发回复，其他功能自动运行。
